# AGENTS.md: global principles (ai-principles)

Hi! Please read these rules in order:

1. `rules/index.md`: the index, so you know what exists.
2. `rules/aip-global-*.md`: **ALWAYS**. These apply to every project.
3. `rules/aip-scoped-*.md`: **ONLY** when the project matches the declared scope.

## Precedence

`repo > scoped > global`: the most specific rule wins.

## Obligation levels

- `[MUST]`: mandatory.
- `[SHOULD]`: recommended; skip it if you have a good reason.
- `[NICE]`: optional, nice to have.

## Identifiers

Each individual rule carries its readable id in braces: `<file>.<rule>`, e.g. `{ aip-global-git.atomic-commits }`.
